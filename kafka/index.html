💻 How to Run the Original Terminal CLI Files

If you want to run Apache Kafka and the original CLI scripts directly in your terminals:

1. Start Kafka via Docker:

docker run -p 9092:9092 bashj79/kafka-kraft

2. Create topic via Admin:

node admin.js

3. Start a Consumer in a terminal:

node consumer.js user-group-1

4. Start Producer in another terminal:

node producer.js
